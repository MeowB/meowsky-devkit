meowsky audit [<directory>] [--quick] [--refresh]
Validate a local workspace directory. Defaults to the current directory.
The directory may be relative to the current location or an absolute path.
Options may appear before or after the directory.

--quick    Select quick analysis. Analysis is not implemented yet.
--refresh  Request a workspace map refresh. Map generation is not implemented
           yet; this option does not write any files.
--help     Show this help when used alone. -h and -Help also show feature help.

Discovery lists relevant source, test, configuration, and documentation files.
It excludes common dependencies, generated output, caches, temporary files, and
.meowsky/. Optional .meowskyignore lines name exact project-relative files or
directories (including their contents); blank lines and # comments are ignored.
Wildcards and parent paths are not supported. Scan limits are 20,000 entries,
30 directory levels, and 30 seconds. Skipped paths and incomplete coverage are
reported; the command does not follow junctions or symlinks.

The inventory stays in memory. Analysis, findings, Codex review, and map
generation are not implemented yet. No target project files are changed.
