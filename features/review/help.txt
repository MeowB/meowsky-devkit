meowsky review [<directory>] [--docs]
meowsky review [<directory>] --interactive [--docs]
meowsky review [<directory>] --complete [<json-file>]
meowsky review [<directory>] --decide <json-file>

Run meowsky audit first. Review requires its current state and verified
MAP.md and AUDIT.md. The directory defaults to the current location;
Git is optional. Review opens the Codex UI from an isolated scratch directory.
Codex may request approval to read project files. It writes a JSON handoff
inside scratch; after you exit the UI with /exit, Meowsky validates it and
writes the reviewed artifacts in the same command. --interactive is an alias
for this default flow. Hooks, plugins, and apps are disabled. Do not approve
requests to write application source or run project tools.

Full review requires the discovered source, test, and configuration files
to be inspected, plus related documentation. Its claimed reviewed paths,
source references, session identity, and audit freshness are validated.
The path list cannot prove what Codex actually read. Interrupted, partial,
or invalid handoffs remain pending; process exit alone does not complete
review. If the UI exits before writing a valid handoff, Review stays pending.
--complete remains available to validate clipboard JSON or an external JSON
file from an active session when recovery is needed.

A completed full review enriches MAP.md and AUDIT.md and creates an
unapproved PLAN.md. Zero justified findings are valid. The proposed plan
does not authorize any refactoring.

Record a rejected or deferred full-review finding with --decide and a
JSON file containing version (1), id (S001 etc.), status (rejected or
deferred), and a concrete rationale. The decision is kept in workflow
state across later audits and shown to future reviews. Changed workspace
inputs and an explicit reopening reason are required to recommend a
rejected or resolved finding again.

--docs limits investigation to architecture and documentation. It updates
the documentation review portions of MAP.md and AUDIT.md without writing
a plan or changing existing valid review approval state.

--help shows this page when used alone.
