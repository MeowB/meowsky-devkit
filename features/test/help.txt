NAME
    meowsky test - run one test against a compiled program

SYNTAX
    meowsky test <program.exe> --input "<text>" --expected "<text>"
    meowsky test --help

EXAMPLES
    meowsky test .\main.exe --input "2 3" --expected "5"
    meowsky test .\main.exe --input "999`n1000" --expected "result: 1000"

    Build first with :CBuild or GCC. Python 3.7 or later must be on PATH.
    To send multiple input lines, use double quotes around the input and
    separate values with `n (a backtick followed by n). The second example
    sends 999 and 1000 on separate lines. Numeric scanf conversions read
    them as numbers. The runner adds a newline after the final value.
    Put the result on its own stdout line. The runner compares that final
    line exactly, preserving spaces and case. Use --expected "" to require
    completely empty stdout.

    The program has five seconds to finish. A pass shows input and result.
    A failure shows the cause, input, expected result, stdout, and stderr.
    0 = pass, 1 = output mismatch, 2 = execution or usage error.

SCRIPT EXAMPLE
    Save this in test.ps1 and run .\test.ps1 from PowerShell after building.
    Set the executable in the function, then put one case on each line.
    The exit check stops the script at the first failed case.

    function Test-Case {
        param([string]$InputText, [string]$Expected)

        meowsky test .\main.exe --input $InputText --expected $Expected
        if ($LASTEXITCODE -ne 0) {
            exit $LASTEXITCODE
        }
    }

    Test-Case '10' 'result: 10'
    Test-Case "999`n1000" 'result: 1000'
