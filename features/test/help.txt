NAME
    meowsky test - run one test against a compiled program

SYNTAX
    meowsky test <program.exe> --input "<text>" --expected "<text>"
    meowsky test --help

EXAMPLE
    meowsky test .\main.exe --input "2 3" --expected "5"

    Build first with :CBuild or GCC. Python 3.7 or later must be on PATH.
    The runner sends UTF-8 input followed by a newline. Use PowerShell
    newline escapes to put multiple values on separate input lines.
    Put the result on its own stdout line. The runner compares that final
    line exactly, preserving spaces and case. Use --expected "" to require
    completely empty stdout.

    The program has five seconds to finish. A pass shows input and result.
    A failure shows the cause, input, expected result, stdout, and stderr.
    In a PowerShell script, check $LASTEXITCODE after each call.
    0 = pass, 1 = output mismatch, 2 = execution or usage error.
