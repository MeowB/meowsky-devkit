# Meo Matrix implementation report

Updated 2026-09-28 to restore mostly Matrix-green terminals. Neon-green ordinary text and pale-green white slots replace neutral terminal text; ANSI highlights and code syntax now use bright, distinct basic colors. Windows accent is fixed at #265934. No live application settings were applied.

## Visual direction and comparison

The terminal reference (`terminal-view-aim.png`), three wallpapers (`left.png`, `center.png`, `right.png`), and three icons (`folder.ico`, `bin-full.ico`, `bin-empty.ico`) in `features/identity/themes/meo-matrix/` were inspected before editing. The left wallpaper establishes dark forest silhouettes and pale emitted Matrix light; the center establishes black architecture, emerald haze and restrained teal; the right establishes near-black working surfaces, mint signage and teal keyboard illumination. The icons repeat black interiors with emerald/teal edges and pale luminous symbols.

The terminal palette restores neon Matrix green #39FF14 on true black. ANSI green uses the same neon hue; ANSI white and bright white use pale greens #8FFFA0 and #C7F9CC. Blue, cyan, and magenta output is bright and saturated. Code uses green keywords, cyan functions, blue types, yellow strings, orange numbers, and magenta constants. Red errors and yellow warnings remain recognizable. UI, Windows personalization, cursor color, and backgrounds retain their existing values. Matrix rain and headers use ANSI green; ordinary terminal text inherits the neon-green foreground.

Assets are design references only. They are never sampled dynamically, loaded by adapters or required at runtime. The JSON is the sole programmatic color source.

## Readability

Calculated sRGB contrast ratios describe solid colors, not perceived comfort or application rendering. Visual verification remains necessary.

| Pair | Contrast |
| --- | --- |
| Ordinary code text / background | 19.90:1 |
| Ordinary code text / raised surface | 16.84:1 |
| Comments / background | 8.08:1 |
| Terminal text / terminal background | 15.49:1 |
| Button labels / accent | 6.97:1 |
| Button labels / hover | 4.54:1 |

The terminal direction is mostly luminous green, with bright secondary categories and red/yellow alerts. Terminal programs choose how much colored output they emit. Dark ANSI black is structural and is not suitable for ordinary text.

### Other runtime surfaces

Meowsky tree files, connectors, ordinary status text, and help inherit neon-green terminal defaults. Matrix rain and headers use ANSI green; folders and paths use bright ANSI blue/cyan. PowerShell command input uses bright ANSI slots through PSReadLine; reload the profile to activate it. Commands/members are cyan, strings yellow, numbers magenta, types/parameters blue, variables/operators pale green, and keywords green. The prompt itself is not configured. Linux/tmux has no Identity adapter; eza trees disable colors. Neovim remains on its independent Tokyo Night true-color theme. Wallpaper/icon assets are unchanged.

## Discovery and verification

Theme discovery accepts `themes/<id>.json` and `themes/<id>/<id>.json`. A duplicate ID across layouts produces an ambiguity error. Folder loading reads only the named definition; adjacent reference files are ignored. Flat definitions remain supported.

Verification for this highlighting update covers Identity, Terminal, VS Code, syntax grammar/merge, and profile/refactor behavior using isolated fixtures. They use isolated temporary settings and mocked OS writes. Syntax verification checks grammar mappings; semantic-provider behavior and actual screen appearance remain manual checks.

Review with `meowsky identity apply meo-matrix --dry-run`. When applying later, inspect the UI beside the three wallpapers and icons, including terminal output, code, selections, inactive text and diagnostics. Neovim integration is not implemented. Project color overrides are retired. Codex, tree, status, and Matrix use the active terminal theme foreground. Legacy color files remain untouched.
